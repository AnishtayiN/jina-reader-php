# 📖 Jina Reader

تبدیل هر صفحه وب به **Markdown تمیز و خوانا** با یک کلیک — قدرت‌گرفته از [Jina AI Reader](https://jina.ai/reader).

## ✨ امکانات

- 🌐 تبدیل سریع هر URL به Markdown (بدون نیاز به بک‌اند — کاملاً سمت کلاینت)
- 🌙/☀️ تم تیره و روشن (با ذخیره خودکار)
- 📑 **فهرست مطالب** خودکار از تیترها (H1 تا H3) با اسکرول نرم
- 🔍 **جستجو در متن** مقاله با هایلایت
- 🔊 **خواندن صوتی** مقاله (فارسی)
- 🔠 تغییر اندازه فونت (+/−)
- 📊 آمار مقاله: تعداد کلمات، کاراکتر و زمان تقریبی مطالعه
- 📋 کپی / ⬇️ دانلود Markdown (نام فایل از عنوان مقاله)
- 🔗 لینک اصلی مقاله
- 🕘 تاریخچه ۶ آدرس آخر (localStorage)
- 🧾 رندر کامل: جدول، کد، بلاک‌کویت، لیست، تسک‌لیست، تصویر و ...
- 📱 **PWA** — قابل نصب و کارکرد آفلاین (service worker)
- 🎨 رابط فارسی راست‌به‌چپ با فونت وزیرمتن

## 🚀 استفاده

1. آدرس صفحه را وارد کنید (یا از پارامتر `?url=` استفاده کنید)
2. دکمه «تبدیل» را بزنید
3. متن Markdown تمیز را بخوانید، کپی کنید یا دانلود کنید

مستقیم باز کنید: `https://<your-domain>/?url=https://example.com`

## 🛠 فایل‌ها

| فایل | نقش |
|------|------|
| `index.html` | کل برنامه (HTML + JS) |
| `styles.css` | استایل و تم |
| `sw.js` | Service Worker برای PWA/آفلاین |
| `manifest.json` | مانیفست PWA |
| `icon.svg` | آیکون برنامه |

## 🧪 اجرای محلی

فقط فایل‌ها را روی هر هاست استاتیک (مثل GitHub Pages) بگذارید یا به‌صورت محلی:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

> ⚠️ Service Worker فقط روی HTTPS یا `localhost` فعال می‌شود.
